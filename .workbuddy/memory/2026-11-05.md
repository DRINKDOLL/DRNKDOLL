## 坑（重要，跨会话复用）

- **Git Bash + Windows Python：正则里 `\{`（转义花括号）在 `re` 中匹配失败**（`re.search(r'menu:\{', s)` 返回 False，而 `re.search(r'menu:{', s)` 返回 True）。写删除/替换脚本时，匹配花括号字面量不要用 `\{`、`[^{}]`，直接写 `{`、`[^}]` 或用 `str.replace` 精确串。
- **bash heredoc 传 Python 时反引号是安全的**（`<<'EOF'` 不展开），但脚本内构造含反引号的 f-string 要小心；建议脚本落盘成 .py 文件再执行，避免转义踩坑。
- jar 回写命令：`"<jdk>/bin/jar.exe" uf "<jar>" "BOOT-INF/classes/ui/ui-assets/xxx.js" "xxx.js.gz"`（先 Stop-Process 停实例，Windows 下 jar 被占用无法写）。

  1. `y=J(!1);` 后插入 `sf` ref + `buildRaw`/`parseFields`/`syncT`；
