## 首页作品网格改 3 列（20:40）

- 诉求：首页作品卡片每行 3 个（原 2 个），缩小图标，响应式兼容。
- 根因：theme-earth 是 Tailwind「按需编译」，改模板里的类名（如 md:grid-cols-3）不会自动生成对应 CSS；且原 grid_3 布局用 xl:grid-cols-3（≥1280px 才 3 列），主内容区受右侧 18rem 侧边栏挤压，实际常显示 2 列。
- 改法（直接改主题模板源文件，重启生效）：
  1. `templates/index.html` 的 `#post-list`：`grid-cols-1 gap-6` → `grid-cols-1 gap-4 sm:gap-5`，grid_3 分支 `md:grid-cols-2 xl:grid-cols-3` → `sm:grid-cols-2 lg:grid-cols-3`（用现成的 lg:grid-cols-3，CSS 已编译存在，1024px 起 3 列）。
  2. `templates/modules/post-card.html`：封面 `aspect-h-9 aspect-w-16`(16:9) → `aspect-h-2 aspect-w-3`(3:2 更矮)；标题 `text-2xl` → `text-lg`。
  3. `templates/modules/hero.html`：站点标题 `text-5xl` → `text-3xl sm:text-4xl lg:text-5xl`（修复移动端换行贴边）。
- 验证：1440px 视口 gridTemplateColumns = 296px×3；390px 移动端单列无溢出。实测 6 条作品三列排列美观。
- 关键教训：改 Tailwind 类名务必用「已编译进 CSS 的类」（grep main-*.css 确认），否则新断点类不生效。

## 首页分类/标签点击不再跳回顶部（20:50）

- 诉求：点击「全部/默认分类/实训项目」等分类项时页面跳回浏览器顶部，要求保持滚动位置。
- 根因：`templates/modules/category-filter.html` 里分类项是普通 `<a href="/categories/xxx">`（「全部」是 `href="/"`），点击触发**整页导航跳转**（服务端重渲染新页面），浏览器默认滚回顶部。非锚点/表单问题。
- 改法（前端局部刷新，阻止默认跳转）：
  1. `modules/category-filter.html`：给每个分类 `<a>` 加 `data-filter`（值用 `categoryItem.metadata.name`，如 cat-sqi57crw，注意「默认分类」的 name 是 UUID）和 `@click.prevent="filterByCategory(...)"`；「全部」加 `data-filter="all"`。
  2. `index.html`：给 `<section>` 加 `x-data="categoryFilter"`；`</body>` 前加 `alpine:init` 注册 `categoryFilter` 组件，含 `filterByCategory`（fetch → 渲染 `#post-list` 的 innerHTML）与 `renderCard`（手写 post-card 的 HTML，字段取 spec.title/cover/slug、status.permalink/excerpt、categories[0].spec.displayName、owner.displayName/avatar、spec.publishTime）。
  3. 空状态 div 加 `id="post-empty"`。
- 关键接口：分类取文要用 **`GET /apis/api.content.halo.run/v1alpha1/categories/{name}/posts`**（total 正确）；`/posts?categoryName=` 参数无效（忽略，返回全量）。「全部」用 `GET .../posts?size=24`。
- 验证：playwright 实测初始 scrollY=400，点「实训项目」后 378（内容变短浏览器自动收窄，非归零），点「全部」6 篇、「实训项目」2 篇、「算法模型」2 篇均正确，无 pageerror。
- 教训：公开 API 分类过滤是独立端点 `/categories/{name}/posts`，不是 posts 列表的 query 参数。

## 隐藏「默认分类」（21:05）

- 诉求：隐藏首页的「默认分类」（Halo 内置兜底分类，非业务分类，且空）。
- 涉及三处入口，分别处理：
  1. 首页分类筛选栏 `modules/category-filter.html`：`th:each` 的 li 加 `th:if="${categoryItem.spec.displayName != '默认分类'}"`。
